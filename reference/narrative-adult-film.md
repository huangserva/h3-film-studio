# 叙事成人片方法论（《金瓶梅·夜宴》119s 实证，2026-08-09）

一部有戏的成人片，不是"铺垫静帧 + 硬核合戏 + 收尾"三段硬拼。这份是从翻车迭代到定版逐轮逼出来的方法。**做叙事成人片先读这份。**

## 铁律一：叙事完整性 > 技术连续性

翻车顺序（黄佬逐轮逼出来的，每条都踩过）：
1. 先去修"帧怎么接"（chain），但真问题是**故事跳**。
2. **别被时长绑架**——该多长多长（60s 会把故事压扁成"独处→突然全裸→突然独坐"）。
3. **一见面就做爱＝假**。要有男方登场、对坐、言语调情。
4. **女主独处不能自己脱**（见铁律二）。
5. 缺的过渡镜头（登场/宽衣/事后/调情）**现有静帧没有就 Krea 补图**，别硬跳。

先立**完整故事线**，再想每一幕用什么镜头，缺画面就补图。

## 铁律二：人物逻辑（金瓶梅＝欲擒故纵 + 威逼利诱）

潘金莲：放荡的欲，裹在保守的矜持里。**独处时端庄候（不脱、不露）**，脱衣戏必须发生在**男方威逼利诱→她半推半就**之后。西门庆：步步进逼——点破她守活寡的空虚、堵死退路（"今夜只有你我"），让她"没有反抗的理由"，她才顺理成章地从（既遂欲又保矜持）。
- **独处段：着装矜持**（本片：白纱高领端坐候）。一旦女主独处就半裸/解衣，人物就垮了。
- **脱衣＝博弈之后**，且是被动半推半就，不是主动。
- 服装线单向：外袍(外出)→ 进屋换寝衣(端庄)→ 博弈(着寝衣)→ 宽衣(褪)→ 裸。**换装别拍成"当众解衣的脱衣戏"**。

## 六幕结构（本片实证）

| 幕 | 内容 | 手法 |
|----|------|------|
| 相引 | 门口→穿廊→进屋换寝衣端庄候 | i2v 慢镜 + 旁白 |
| 登场 | 男推门入 → 隔案对视 | i2v |
| 博弈（核心）| 对坐递酒 → 搭肩初吻(坐) → 相拥半推→沉沦(立) | 递酒 i2v + **表情戏 fl2v** + 对白 |
| 宽衣 | 解带褪衣 → 半裸前戏 | i2v |
| 交欢 | 全裸相就 → 连续交合 | i2v **chain** |
| 余韵 | 事后平复 → 独坐回味 | i2v + 旁白 |

**顺序纪律**：亲密度只增不减（坐姿挑逗必须在立姿相拥之前，否则"相拥了又退回搭肩"）。

## 手法映射（三种，按戏选）

- **i2v 慢镜**：文戏铺垫。注意 i2v 从静帧启动，头尾偏静、微表情几乎不动（motion 0.3–0.6）。配旁白就是电影感的慢；纯静态别指望它演表情。
- **fl2v 表情戏**（博弈关键）：微表情博弈 i2v 演不动（0.3 死）。给**首尾两个表情态**（F1 推拒 → F3 沉沦），fl2v 补中间心理转变（motion 1.3–2.2，"从抗拒到融化"演出来）。这是 fl2v 的正确用途（首尾差大），不是 morph 死。graph 见 `scripts/fl2v_build.py`（timelineMode=fl2v，segments 带 genImage=首帧 + endImage=尾帧）。
- **i2v chain 连续**（交欢）：上段尾帧当下段首帧，无缝、消慢启动停顿（motion 6–10）。代价：体位锁在起始态（一路立姿），要体位变化得分块 chain + 块间转场。

## 对白与旁白（H3 对不上中文口型的解法）

- **旁白**（叙述/内心）：`cosyvoice3-female-anchor`，画外音 mouth-closed，不穿帮。
- **对白**（角色说话）：博弈段侧脸/亲密姿态嘴不明显 → **配音蒙混**。男 `first120-male`（西门庆）+ 女 `taichi-douyin-young-female`（潘金莲），三声区分。按**问答流**铺（进逼↔推拒），不严格绑段。逐字对唇要另上数字人。
- CosyVoice3：`POST 127.0.0.1:8001/tts` `{text, voiceId, speed, instruct}`，19 音色，`instruct` 加情感（"低沉暧昧气声"），返回 JSON 带 `path`/`download_url`。

## 音频四层（缺一就是半成品）

1. **人声/喘息**：H3 交欢段自带音（**禁 mute**），volume gate 只留交欢时段。
2. **对白**：男女双声，博弈段按时间码。
3. **旁白**：铺垫/余韵点睛，交欢段留白。
4. **Foley**：夜景底噪（ffmpeg anoisesrc brown + lowpass）。BGM 第四层暂缺源。
混音：speech(前景) > voice(中) > foley(低垫)，amix + loudnorm I=-16。

## 工程坑（都踩过）

- **Krea(8188) 与 H3(8190) 共享 4090 显存，互斥**：补图↔跑视频切换前必须 `POST /free`，否则 OOM。
- **frames 必须落 17k+5 网格**（124 等）；H3 起始帧 resize 到 480×864 再上传。
- **scp 大批量易截断**：拼接前 `ffprobe -count_frames` 校验每段 124f。
- macOS 无 `timeout`；盒上 `/usr/bin/python3.12` 要 `pip install --break-system-packages aiohttp`。
