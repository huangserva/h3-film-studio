## 一、人物设定（不许走样）

### 潘金莲
- **本质是欲女**，心里有欲望、不安分
- **但表面必须守贞洁、矜持**——欲擒故纵，不能显得轻浮
- **绝不主动**：不能自己脱衣、不能主动投怀送抱
- **必须"被逼"才就范**：嘴上推拒（「使不得」「饶了妾身」），身体却不真的躲开
- 就范之后才能显露欲女本色（主动、放纵）

### 西门庆
- 35岁明代商贾：**黑色网巾（wangjin）+ 短黑须 + 浓眉 + 宽肩 + 成熟男性脸**
- **裸戏也必须保留网巾和短须**（模型倾向画年轻裸男 → 每句 prompt 复述）
- 手段：**威逼 + 利诱**，不是靠魅力
  - 威逼：拿住把柄（武大的事）→「我都晓得」「这事便烂在我肚子里」
  - 利诱：银两、绫罗绸缎、吃穿不愁
  - **目的：让她"没有反抗的理由"、退无可退**

## 二、剧情铁律（缺一条就是垮）

1. **不能一见面就做爱**——必须有对坐、饮酒、言语调情的过程
2. **必须有"威逼利诱"这一幕**，且在宽衣之前：
   把柄威胁 → 她惊惶 → 要挟 → 她求饶 → 利诱 → 她动摇 → 认命
3. **每个环节都要有画面交代**，不许跳：
   相引 → 登场 → 调情 → **威逼利诱** → 半推半就 → 宽衣 → 前戏 → 交欢 → 余韵
4. **不要被时间绑架**——该多长就多长，宁可片长翻倍也不能省环节
5. 女主独处时**着装矜持**（换好寝衣端坐候），脱衣戏一律在威逼之后

## 三、技术铁律

### 音频
- **必须 H3 原声（音画同出）**，`audio_mode=native`
- **绝对禁止 TTS 外部配音**（CosyVoice 等）——说过无数次
- T8 multi-rate：`video_steps=4` / `audio_steps=8`（turbo 一刀切4步会糊音频）
- **中文只用来写台词**（写在「」里）；**绝不用中文写 Audio 描述**（H3 会把那句中文念出来）
- 无台词镜：不写 Audio 行；出片后若仍有乱码人声 → 静音

### 台词字幕烧进画面（2026-08-09 新发现）
- 现象：prompt 里写「台词」，H3 有时会把台词**渲染成中文字幕烧进画面**（c04/c05 中招）
- 待验证的解法：①台词前加"不要出现字幕/文字"②台词改用括号或其他标记 ③出片后检测画面文字→重 roll
- **交付前必查**：抽帧看画面有没有多余文字

### 镜头
- **每个 shot 必须讲完整**，动作有始有终，不能没演完就切
- **帧数按内容定**，不是固定 124：
  反应 71-124 / 对话 124-141 / 建立 141-192 / **动作过程 192-243** / 交欢 243-362
- **纯 i2v 机位稳定**；fl2v 首尾帧构图不同会导致**镜内画面全程漂移**（慎用）
- prompt 动作描述**明确但不复杂**：
  - ❌ 太复杂："一手托背一手扶头缓缓平放躺倒" → 演不出，乱动
  - ❌ 太简："女子躺下，男子俯身" → 自由发挥，演错
  - ✅ "坐在床沿的女子慢慢向后躺倒在床上，男子跟着俯身靠近她"

### 衔接（最关键）
- **shot 之间的衔接必须在导演设计阶段做好，剪辑救不了**
- 分镜表每一镜必须写清：**起始状态 = 上一镜的结束状态**（人物姿态/位置/视线完全承接）
- **机位要换角度**（30°以上），否则同机位硬切 = 跳切
- 机位序列要有设计：正面全景 → 过肩 → 侧面 → 斜侧近景 → …

### 一致性
- **角色 bible 每张母图逐字复述**（漏了就变人）
- **空间锚**：同一场景用完全相同的空间描述 + 同 seed 族
- 三重锚缺一不可：人物 bible + 空间锚 + 同 seed 族

## 六、第二轮验收暴露的根子问题（2026-08-09，黄佬在 Fable 5 上逐条揪出）

### 6.1 男主穿戴/脸飘 —— 一致性根子：不能靠文字，要靠参考图
- **黄佬原话**："男主人物穿戴都有变，你是不是不知道如何控制主角一致性？"
- **确认**：c03 是另一种质地的棉夹袄，和别处圆领袍不是一件衣服；脸型也飘。
- **根因**：一直用"文字 bible 复述"控一致性。文字锁不住衣服剪裁/面料/脸几何。每张母图独立生成 → 必然飘。
- **正解（reference_character，之前写进 skill 却没真用）**：
  1. 先做一张**角色参考图**（西门庆、潘金莲各一张干净全身定妆照）
  2. 每张场景母图用**身份锁节点**（IPAdapter / InstantID / PuLID / Qwen-image-edit，看盒子装了哪个）把角色参考注入，再从文字生成新构图/新机位
  3. **禁止**只靠重写文字 bible 就指望一致

### 6.2 台词被 H3 渲染成字幕烧进画面
- c04 画面烧入"官人饶了妾身罢""妾身实在不敢"。
- **交付前必抽帧查画面文字**，有字幕 → 重 roll 或改台词写法。**上轮记了没修就交付＝违反自检门，不许再犯。**

### 6.3 二元音频策略造成长段死寂
- **黄佬原话**："33秒到57秒没有声音了！"
- **根因**：音频要么 H3 说话、要么整段静音。连续两个无台词镜被静音 = 18 秒死寂。
- **正解**：全片铺一条**连续的环境底噪/Foley**（烛火、夜虫、衣料、脚步），H3 对白叠在上面。**永远不许有死寂**。走位镜要有脚步声。

### 6.4 情绪转折也要过渡，硬切不行
- **黄佬原话**："1:06秒说使不得，然后就硬切到1:07秒的shot了吗？如果是使不得，只要也要有点过渡对不对？"
- 推拒→接吻 之间缺"他坚持、她再挣扎、手慢慢松开"的中间拍，且下镜首帧≠上镜尾帧。
- **正解**：情绪转折镜之间也要 chain（下镜首帧=上镜尾帧）或补中间拍。**不只是动作要过渡，情绪转折更要过渡。**


### 6.5 【硬规则】H3 绝不允许自己出字幕
- **黄佬原话**："我们不允许做字幕，字幕都必须是后做的，不允许H3自己做字幕"
- H3 会把 prompt 里的「台词」渲染成字幕烧进画面（c04 中招）。
- **对策（需验证）**：①视频 prompt 里台词末尾加英文抑制 "no on-screen text, no subtitles, no captions" ②出片必抽帧查画面文字，有字 → 换 seed 重 roll ③字幕若要，纯后期加。
- **交付前抽帧查字：有任何烧入文字＝不合格。**


### 6.1-FIX 一致性解法已验证：Qwen-Image-Edit-2511 参考图注入（2026-08-09 验证通过）
**锚定参考图（永久，不许换）**：西门庆=`REF_XM.png`(源 D_XM，网巾+短须+圆领袍)；潘金莲=`REF_PJ.png`(源 ds_pj，白高领袍+发髻)。
**每张母图都用 Qwen-Edit 生成，把参考图注入**：
- 盒(8188 Krea 实例)：`qwen_image_edit_2511_fp8_lightning_4steps` + CLIP `qwen_2.5_vl_7b_fp8_scaled`(type qwen_image) + VAE `qwen_image_vae`
- 接线：UNETLoader→ModelSamplingAuraFlow(3.1)→CFGNorm(1)→KSampler(4步,cfg1,euler,simple)；TextEncodeQwenImageEditPlus(image1=主参考经FluxKontextImageScale, image2/3=其他参考, prompt)→FluxKontextMultiReferenceLatentMethod(index_timestep_zero)→KSampler±；VAEEncode(scaled)→latent
- 双人镜：image1=REF_XM image2=REF_PJ；女特写：image1=REF_PJ；男特写：image1=REF_XM
- prompt 末尾必带 `no on-screen text, no subtitles, no captions`
- 脚本：scratchpad `qwen_edit_test.py`（可复用 build()）
**验证结果**：两张脸/网巾胡须/白袍发髻锁死，跨 seed 一致。**从此禁止只靠文字 bible 生成母图。**


### 6.5-FIX 禁字幕 directive 不可靠 → 唯一可靠办法是多 seed 挑干净（2026-08-09 验证）
- 测试：sub_xm(西门庆) + sub_pj(潘金莲) 同加 `no on-screen text, no subtitles` 指令。**sub_xm 干净、sub_pj 仍烧字幕**（还多一行乱码英文）。
- **结论：prompt 禁字幕指令拦不住 H3，字幕是随 seed 的抽卡。**
- **可靠办法**：台词镜**多 seed 生成（3+），抽帧挑无字幕的那条**（干净 seed 是多数）。禁字幕指令仍加（无害、可能降概率），但不能依赖它。
- **交付前逐台词镜抽帧查字，有字＝换 seed 重跑，不许进成片。**


### 6.6 中文舞台指示也会被烧成字幕（2026-08-09 新发现）
- k02 画面烧入「全程没有」—— 那是我 prompt 里的**舞台指示**"她嘴唇闭合，全程没有说话"，不是台词。
- **结论：H3 会把 prompt 里任何中文句子渲染成字幕，不限于「」台词。**
- **对策**：
  - 中文**只写**：场景描述 + 「台词」
  - **舞台指示/表演提示一律用英文写**（如 `She stays completely silent with her lips closed throughout.`）
  - 仍需逐镜抽帧查字，有字换 seed 重跑


### 6.7 字幕的真正根因：母图里人物张嘴 → H3 认定他在说话 → 自动配乱码语音+字幕
- k02 无台词镜连换 2 seed + 英文舞台指示**都还烧字幕**（乱码中文）。查母图：**QM_s2 里女主是微张嘴的表情**。
- **结论**：H3 看图判断"这个人在说话"，就自己编一段语音并烧字幕。**prompt 拦不住图里的嘴。**
- **正解（分两类）**：
  - **无台词镜**：母图必须是**嘴唇紧闭**的（Qwen-Edit 出图时写死 `Her MOUTH IS FIRMLY CLOSED, lips pressed together, absolutely not speaking`）
  - **有台词镜**：母图可以张嘴，台词写「」，出片抽帧查字，有字换 seed
- **顺序纪律**：先按"该不该说话"设计母图表情，再跑视频。别等出了字幕再补救。


### 6.8 环境音不许用合成噪声；无台词镜会瞎发人声（2026-08-11 黄佬指出）
- **黄佬原话**："背景一直有噪音" / "中间有一段没有声音"
- **两层病因**：
  1. 我用 `anoisesrc` 合成 brown/white noise 当环境音 —— **那本质就是噪声，不是真实烛火夜虫**，有对白时嫌吵、没对白时又撑不住。
  2. **无台词镜 H3 仍在瞎发人声**：实测 k06/k07 人声频段能量 -17.3/-18.1dB，**比真有台词的 k03/k09(-23.4/-22.8dB) 还高**。
- **正解：空镜环境音床**——用一张**画面里没有人**的空房间图跑 H3（`Audio: quiet room tone, soft candle crackle, distant night insects. No voices, no speech.`），画面没人就不会生成人声，得到**H3 原生的真实环境音**，循环铺满全片。
- **无台词镜一律丢弃自带音频**（它必然瞎发声），用环境音床代替。
- **禁止**再用 anoisesrc/合成噪声冒充环境音。
