## 一、人物设定（不许走样）

### 潘金莲
- **本质是欲女**，心里有欲望、不安分
- **但表面必须守贞洁、矜持**——欲擒故纵，不能显得轻浮
- **绝不主动**：不能自己脱衣、不能主动投怀送抱
- **必须"被逼"才就范**：嘴上推拒（「使不得」「饶了妾身」），身体却不真的躲开
- 就范之后才能显露欲女本色（主动、放纵）

### 西门庆
- 35岁明代商贾：**黑色网巾（wangjin）+ 短黑须 + 浓眉 + 宽肩 + 成熟男性脸**
- **裸戏也必须保留网巾和短须**（模型倾向画年轻裸男 → 每句 prompt 复述）
- 手段：**威逼 + 利诱**，不是靠魅力
  - 威逼：拿住把柄（武大的事）→「我都晓得」「这事便烂在我肚子里」
  - 利诱：银两、绫罗绸缎、吃穿不愁
  - **目的：让她"没有反抗的理由"、退无可退**

## 二、剧情铁律（缺一条就是垮）

1. **不能一见面就做爱**——必须有对坐、饮酒、言语调情的过程
2. **必须有"威逼利诱"这一幕**，且在宽衣之前：
   把柄威胁 → 她惊惶 → 要挟 → 她求饶 → 利诱 → 她动摇 → 认命
3. **每个环节都要有画面交代**，不许跳：
   相引 → 登场 → 调情 → **威逼利诱** → 半推半就 → 宽衣 → 前戏 → 交欢 → 余韵
4. **不要被时间绑架**——该多长就多长，宁可片长翻倍也不能省环节
5. 女主独处时**着装矜持**（换好寝衣端坐候），脱衣戏一律在威逼之后

## 三、技术铁律

### 音频
- **必须 H3 原声（音画同出）**，`audio_mode=native`
- **绝对禁止 TTS 外部配音**（CosyVoice 等）——说过无数次
- T8 multi-rate：`video_steps=4` / `audio_steps=8`（turbo 一刀切4步会糊音频）
- **中文只用来写台词**（写在「」里）；**绝不用中文写 Audio 描述**（H3 会把那句中文念出来）
- 无台词镜：不写 Audio 行；出片后若仍有乱码人声 → 静音

### 镜头
- **每个 shot 必须讲完整**，动作有始有终，不能没演完就切
- **帧数按内容定**，不是固定 124：
  反应 71-124 / 对话 124-141 / 建立 141-192 / **动作过程 192-243** / 交欢 243-362
- **纯 i2v 机位稳定**；fl2v 首尾帧构图不同会导致**镜内画面全程漂移**（慎用）
- prompt 动作描述**明确但不复杂**：
  - ❌ 太复杂："一手托背一手扶头缓缓平放躺倒" → 演不出，乱动
  - ❌ 太简："女子躺下，男子俯身" → 自由发挥，演错
  - ✅ "坐在床沿的女子慢慢向后躺倒在床上，男子跟着俯身靠近她"

### 衔接（最关键）
- **shot 之间的衔接必须在导演设计阶段做好，剪辑救不了**
- 分镜表每一镜必须写清：**起始状态 = 上一镜的结束状态**（人物姿态/位置/视线完全承接）
- **机位要换角度**（30°以上），否则同机位硬切 = 跳切
- 机位序列要有设计：正面全景 → 过肩 → 侧面 → 斜侧近景 → …

### 一致性
- **角色 bible 每张母图逐字复述**（漏了就变人）
- **空间锚**：同一场景用完全相同的空间描述 + 同 seed 族
- 三重锚缺一不可：人物 bible + 空间锚 + 同 seed 族

## 四、工程

- Krea(8188) 与 H3(8190) 共享显存 → 切换前 `POST /free`
- 宽高被 32 整除（用 864 不用 854）；帧数落 17k+5 网格
- 经跳板 scp 易断 → 用 rsync + ControlMaster，启动后 `pgrep` 确认进程
- 盒上跑脚本用 `setsid ... < /dev/null &`
